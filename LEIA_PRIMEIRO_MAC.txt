CONTROLE DE ESTOQUE - INSTALACAO NO MAC

1. Descompacte este arquivo ZIP no Mac.

2. Abra a pasta descompactada.

3. Entre na pasta app.

4. Abra o Terminal:
   - Pressione Command + Espaco.
   - Digite Terminal.
   - Pressione Enter.

5. No Terminal, entre na pasta app.
   Dica facil:
   - Digite: cd
   - Deixe um espaco depois do cd.
   - Arraste a pasta app para dentro do Terminal.
   - Pressione Enter.

6. Rode este comando:

   npm run macos:preflight

7. Se aparecer que falta Node, Rust ou Xcode Command Line Tools, siga a mensagem indicada.

8. Para testar o app no Mac:

   npm install
   npm run tauri:dev

9. Para gerar o instalador DMG:

   npm run macos:build

10. O instalador final fica em:

   app/src-tauri/target/release/bundle/dmg

11. Se o macOS bloquear a abertura:
   - Abra Ajustes do Sistema.
   - Va em Privacidade e Seguranca.
   - Clique em Permitir Mesmo Assim / Abrir Mesmo Assim.

OBSERVACAO IMPORTANTE:
O instalador real de Mac precisa ser gerado em um Mac. Este pacote ja esta preparado para isso.
